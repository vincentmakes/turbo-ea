# Digital Autonomy Assessment

تُدخل إضافة **Digital Autonomy Assessment** إطارَ **Digital Autonomy Assessment
Framework (DAAF)** الصادر عن جامعة أوترخت إلى Turbo EA على مستوى التطبيقات. فهي
تضيف قسم **Digital Autonomy** إلى كل بطاقة تطبيق — 22 مؤشرًا مرجّحًا موزّعة على
التعرّض للمخاطر، وقدرة التخفيف، والأهمية الاستراتيجية، ويُقيَّم كل منها من 1 إلى 5
وفق المعيار الأصلي لـ DAAF مع إرشاد مدمج — وتحسب تلقائيًا درجة استقلالية من 1 إلى
10، وترسم محفظتكم بأكملها على **مخطط أرباع الاستقلالية**.

وهي تجيب عن سؤال تتركه معظم خرائط المشهد التقني معلّقًا: *لو أصبح هذا المورّد غدًا
غير متاح، أو غير محتمل التكلفة، أو غير قابل للاستخدام قانونيًا، فما مدى تعرّضنا وما
الذي يمكننا فعله فعليًا؟*

!!! note "لغة الواجهة"
    محتوى هذا الإطار متاح بالإنجليزية والألمانية والفرنسية والإسبانية والإيطالية
    والدنماركية. أما في الواجهة العربية فيظهر القسم والمؤشرات **بالإنجليزية**، ولذا
    تَرِد التسميات المقتبسة أدناه كما تظهر على الشاشة تمامًا.

## البدء

1. ثبّتوا الإضافة من **الإدارة → الإضافات**. لا ترخيص يُطبَّق ولا إعادة تشغيل —
   تظهر الحقول فورًا.
2. امنحوا `ext.digital-autonomy.view` في **الإدارة → المستخدمون والأدوار** للأدوار
   التي ينبغي أن ترى التقرير. أما المديرون فيملكونها أصلًا.
3. قرّروا أتريدون التقييم **السريع** أم **الكامل** — انظر
   [التقييم السريع أم الكامل](#التقييم-السريع-أم-الكامل). النسخة الكاملة ذات الـ22
   مؤشرًا مفعّلة افتراضيًا.
4. قيّموا تطبيقاتكم، بطاقةً بطاقة أو [عبر استبيان](#جمع-التقييمات-عبر-استبيان).

## المؤشرات

يظهر قسم **Digital Autonomy** في كل بطاقة تطبيق، مجمّعًا في ثمانية أبعاد (A–H).
ويُقيَّم كل مؤشر من **1 إلى 5** وفق معياره الخاص.

![قسم «Digital Autonomy» في بطاقة تطبيق](../assets/img/en/65_ext_digital_autonomy_indicators.png)

انقروا رقمًا لمنح التقييم؛ وانقروا الرقم المحدَّد مرة أخرى لمسحه. وعند تمرير المؤشر
فوق رقم يظهر نص المعيار الخاص بذلك المستوى، كما يحمل كل مؤشر **مساعدة** قابلة
للطي تتضمن ملاحظة DAAF وتعريفات المصطلحات التي يستخدمها (*قرار الكفاية*،
*CLOUD Act*، *FISA 702* وغيرها).

المؤشرات الموسومة بـ**سريع** هي التي تُكوِّن التقييم السريع.

| البُعد | المؤشر | الوزن | سريع |
|---|---|---|---|
| **A · المخاطر الجيوسياسية والامتثال القانوني** | A1 · Supplier jurisdiction | 3 | ✔ |
| | A2 · Sanctions and geopolitical risk | 2 | |
| | A3 · Hosting and data location | 2 | ✔ |
| **B · الاعتماد على المورّد وسلسلة التوريد** | B1 · Vendor concentration | 3 | ✔ |
| **C · المرونة التقنية** | C1 · Alternative available | 3 | ✔ |
| | C2 · Migratability | 3 | |
| | C3 · Data portability | 3 | |
| | C4 · Encryption management | 2 | |
| | C5 · Software transparency and openness | 3 | |
| **D · المرونة التنظيمية** | D1 · Internal expertise and knowledge continuity | 3 | ✔ |
| | D2 · Exit plan in place | 3 | |
| | D3 · Backup strategy | 2 | |
| **E · المرونة التعاقدية** | E1 · Exit clauses and transition arrangement | 3 | ✔ |
| | E2 · Contractual flexibility | 2 | |
| **F · الأهمية التنظيمية** | F1 · Impact on outage | 3 | ✔ |
| | F2 · Integration dependencies | 2 | |
| **G · حساسية البيانات وإدارة الوصول والسياسات** | G1 · Personal data | 3 | ✔ |
| | G2 · Research data and knowledge security | 3 | |
| | G3 · Intellectual property | 2 | |
| **H · الأثر الأكاديمي** | H1 · Academic freedom | 3 | ✔ |
| | H2 · Research collaboration | 2 | |
| | H3 · Long-term archiving | 2 | |

!!! note "أي اتجاه هو الجيد؟"
    ليست المعايير كلها متجهة الاتجاه نفسه، وعنصر الواجهة يلوّنها تبعًا لذلك. ففي
    مؤشرات **المخاطر** (A وB وF وG وH) يكون **1 هو الأفضل** — فالمستوى 1 في A1 هو
    مثلًا «EU/EEA jurisdiction. No extraterritorial claims. Full EU protection.»
    والمستوى 5 هو «No adequacy decision, no safeguards. Direct access by foreign
    governments.» أما في مؤشرات **القدرات** (C وD وE) فيكون **5 هو الأفضل**. ولستم
    بحاجة إلى تذكّر ذلك: فالأزرار متدرجة الألوان وموسومة عند طرفيها بـ**Low**
    و**High**.

## الدرجة

يقع قسم **Digital autonomy score** للقراءة فقط أسفل المؤشرات، ويُعاد حسابه تلقائيًا
عند كل حفظ.

![درجة الاستقلالية الرقمية المحسوبة في بطاقة تطبيق](../assets/img/en/64_ext_digital_autonomy_score.png)

| الحقل | المعنى |
|---|---|
| **Risk exposure** | المتوسط المرجّح للبُعدين A (الجيوسياسي) وB (تركّز المورّدين) |
| **Mitigation capacity** | المتوسط المرجّح للمرونة التقنية (C) والتنظيمية (D) والتعاقدية (E) |
| **Strategic importance** | المتوسط المرجّح لـ F (الأهمية التنظيمية) وG (حساسية البيانات) وH (الأثر الأكاديمي) |
| **Digital autonomy score** | رقم واحد من 1 إلى 10 يُعرض على هيئة مقياس |

**كلما ارتفع الرقم كان أفضل** — فالعشرة مثالية والواحد عاجل.

!!! warning "التقييم الجزئي لا ينتج أي درجة على الإطلاق"
    جميع المعادلات محميّة: فإذا نقص ولو مؤشر واحد لازم بقيت الدرجة فارغة بدلًا من
    إظهار رقم مضلّل. ولا يظهر التطبيق في تقرير الأرباع إلا بعد اكتمال تقييمه.

ولأن الدرجات تُحفظ في البطاقة شأنها شأن أي حقل آخر، فهي متاحة في كل مكان: في
المخزون، وفي المرشّحات، وفي عمليات التصدير، وفي تقاريركم الخاصة.

## التقييم السريع أم الكامل

تتضمن الإضافة **نسختين من الحسابات الأربعة نفسها** — إحداهما تقرأ المؤشرات الـ22
كلها، والأخرى تقرأ التسعة الخاصة بالتقييم السريع فقط. والزوج **المفعَّل** هو الذي
يحدد ما يُحسب *وكذلك* عدد المؤشرات التي تعرضها البطاقة.

بدّلوا بينهما من **الإدارة → نموذج البيانات → الحسابات**:

- **التقييم الكامل (الافتراضي)** — الصفوف الأربعة *Digital Autonomy — … (full)*
  مفعّلة، وصفوف *(quick)* معطّلة. وتعرض البطاقات المؤشرات الـ22 كلها.
- **التقييم السريع** — فعّلوا الصفوف الأربعة *Digital Autonomy — … (quick)*
  وعطّلوا الصفوف الأربعة *(full)*. وتعرض البطاقات المؤشرات التسعة السريعة فقط،
  وتُحسب الدرجة على أساسها.

!!! tip "لا يوجد مفتاح عرض منفصل"
    هذا الخيار الواحد في الحسابات هو المبدّل بأكمله. فما إن تُفعَّل المجموعة
    السريعة حتى تُخفي البطاقة تلقائيًا المؤشرات الـ13 الخاصة بالتقييم الكامل، ويتبع
    التقرير الإعداد نفسه. ولا تُفعّلوا النسختين معًا أبدًا — فهما تكتبان في الحقول
    نفسها.

## جمع التقييمات عبر استبيان

بدلًا من تعبئة 22 مؤشرًا لكل تطبيق بأنفسكم، اسألوا من يعرف. استخدموا **جديد من
قالب** في **الإدارة → الاستبيانات**:

- **New DAAF survey — Quick (9)** ينشئ مسودة *DAAF Quick Scan*.
- **New DAAF survey — Full (22)** ينشئ مسودة *DAAF Full Assessment*.

يستهدف كلاهما بطاقات التطبيق ويُفتحان بوصفهما **مسودة** في منشئ الاستبيانات، فلا
يُرسل شيء قبل مراجعتكم. اختاروا دور صاحب المصلحة الذي ينبغي أن يتلقّاه (وأي
مرشّحات — مرحلة من دورة الحياة أو نوعًا فرعيًا) ثم أرسِلوه. ويرى المجيبون عنصر
التقييم نفسه من 1 إلى 5 والمساعدة المدمجة نفسها الموجودة في البطاقة؛ وعند تطبيق
الردود تُكتب الدرجات في البطاقات.

ويمكنكم إنشاء استبيان جديد من قالب كلما شئتم — فإعادة التقييم السنوية ليست سوى
نقرة واحدة.

## تقرير أرباع الاستقلالية

يعرض **التقارير → Digital Autonomy** كل تطبيق اكتمل تقييمه.

![تقرير «Autonomy quadrant»](../assets/img/en/63_ext_digital_autonomy_quadrant.png)

المحور الأفقي هو **المخاطر × الأهمية الاستراتيجية**، والمحور الرأسي هو **قدرة
التخفيف** (المرتفعة في الأعلى)، فينتج أربعة أرباع:

| الربع | ما يعنيه | ما ينبغي فعله |
|---|---|---|
| **Optimal** | تعرّض منخفض وتخفيف قوي | الحفاظ عليه ومراقبته دوريًا. |
| **Manageable** | تعرّض مرتفع، لكن مع بديل احتياطي متين | مخاطر مقبولة في ظل بديل متين. |
| **Attention** | تعرّض منخفض وتخفيف ضعيف | بناء التخفيف أو قبول المخاطرة عن وعي. |
| **Critical** | تعرّض مرتفع وتخفيف ضعيف | إجراء عاجل: الترحيل أو التخفيف. |

كل نقطة مرقّمة وتقابل صفًا في القائمة المجاورة للمخطط، وهي **مرتّبة تصاعديًا حسب
الدرجة — الأكثر إلحاحًا أولًا**. والنقر على أي نقطة أو صف يفتح التطبيق في لوحة
جانبية دون مغادرة التقرير.

**المرشّحات والمحاور**

- تتيح لكم قوائم **Risk exposure** و**Mitigation capacity** و**Strategic
  importance** وضع حقول رقمية أخرى على كل محور — وهو أمر مفيد إن كنتم تمسكون
  مؤشرات مكافئة خاصة بكم. ويُحفظ اختياركم في المتصفح.
- ويضيّق **دورة الحياة** و**النوع الفرعي** نطاق المعروض.

ويمكن حفظ التقرير ومشاركته وطباعته وتصديره كالمعتاد. ويظهر أي عرض محفوظ في
**التقارير → المحفوظة**.

## الصلاحيات

| الصلاحية | تتيح |
|---|---|
| `ext.digital-autonomy.view` | الاطلاع على تقرير **التقارير → Digital Autonomy** |

أما تقييم المؤشرات فيستخدم صلاحيات **التحرير** المعتادة لبطاقات التطبيق: فمن يستطيع
تحرير تطبيق يستطيع تقييمه. ويتطلب التبديل بين التقييم السريع والكامل، وكذلك إنشاء
الاستبيانات من القوالب، صلاحيات المدير المعتادة على **الحسابات** و**الاستبيانات**.

## إذا عُطِّلت الإضافة أو أُزيلت

يؤدي التعطيل أو إلغاء التثبيت إلى إزالة القسمين من نوع البطاقة، لكنه **لا يمسّ
إطلاقًا القيم المحفوظة في بطاقاتكم**. أعيدوا تفعيل الإضافة فتعود كل درجة كما كانت
تمامًا. وتُدمج الحقول دمجًا إضافيًا، فتُحفظ كذلك الحقول التي أضافها مديروكم بأنفسهم
داخل تلك الأقسام.

## اللغات

تتوفر تسميات المؤشرات والأسئلة والمعايير ونصوص المساعدة بالإنجليزية والألمانية
والفرنسية والإسبانية والإيطالية والدنماركية. أما في البرتغالية والصينية والروسية
والعربية فيعود محتوى الإطار إلى الإنجليزية — إذ لا يوفّر الإطار الأصلي تلك اللغات.
