# Ops API (управляемые развёртывания)

Ops API (`/api/v1/ops`) — это **необязательный** интерфейс управления, который плоскость управления Turbo EA Cloud использует для работы с размещёнными экземплярами. В самостоятельно размещённой установке он **по умолчанию отключён**: каждый маршрут отвечает `404`, если экземпляр не запущен с переменной окружения `OPS_PUBLIC_KEY`. В самом Turbo EA нет логики выставления счетов или лицензирования.

## Аутентификация

Каждый запрос Ops должен быть подписан **закрытым** ключом Ed25519, хранящимся у плоскости управления; экземпляр проверяет подпись с помощью **открытого** ключа из `OPS_PUBLIC_KEY` (base64, 32 необработанных байта). Подпись охватывает HTTP-метод, путь с параметрами запроса, хеш тела SHA-256, временную метку и одноразовый nonce:

```
canonical = METHOD \n PATH_WITH_QUERY \n sha256(body) \n timestamp \n nonce
```

Заголовки: `X-Ops-Timestamp` (секунды Unix, ±5 минут), `X-Ops-Nonce` (используется один раз, защита от повторного воспроизведения), `X-Ops-Signature` (подпись Ed25519 в base64).

## Конечные точки

| Метод | Путь | Назначение |
|--------|------|---------|
| GET | `/api/v1/ops/info` | Версия, количество пользователей/карточек, состояние базы данных |
| POST | `/api/v1/ops/rescue-access` | Создаёт **временную** учётную запись администратора-оператора |
| DELETE | `/api/v1/ops/rescue-access` | Немедленно отзывает учётную запись аварийного доступа |
| GET | `/api/v1/ops/export` | Передаёт поток пакета экспорта рабочего пространства без секретов |

## Аварийный доступ — гарантии прозрачности

Временный доступ оператора («аварийный доступ») устроен так, чтобы он никогда не оставался незамеченным:

- **О каждом предоставлении и отзыве доступа уведомляются все администраторы экземпляра** в приложении *и* по электронной почте; в уведомлении указаны имя оператора, причина и время истечения доступа.
- **Каждое действие записывается в собственный журнал событий экземпляра.**
- **Срок доступа контролирует сам экземпляр**: у аварийных учётных записей есть временная метка `access_expires_at`; просроченные учётные записи отклоняются при аутентификации и деактивируются фоновой задачей, запускаемой каждый час. Сбой плоскости управления не может продлить доступ.
- Для аварийных учётных записей используется специально зарезервированный адрес (`rescue-…@rescue.turboea.invalid`), поэтому их легко распознать в списке пользователей и при необходимости отключить вручную.

## Экспорт рабочего пространства

`GET /api/v1/ops/export` возвращает тот же пакет, что и **Администрирование → Настройки → Миграция → Перенос рабочего пространства → Экспорт**: всё рабочее пространство без секретов. Плоскость управления использует его для экспорта данных по запросу клиента (переносимость данных GDPR) и для резервного копирования перед обновлением или удалением.
