# واجهة العمليات (عمليات النشر المُدارة)

واجهة العمليات (`/api/v1/ops`) هي واجهة إدارة **اختيارية** تستخدمها لوحة تحكم Turbo EA Cloud لتشغيل المثيلات المستضافة. وهي **معطّلة افتراضيًا** في التثبيت المستضاف ذاتيًا — وتُرجع جميع المسارات `404` ما لم يبدأ المثيل مع متغير البيئة `OPS_PUBLIC_KEY`. لا يتضمن Turbo EA نفسه أي منطق للفوترة أو الترخيص.

## المصادقة

يجب توقيع كل طلب عمليات بالمفتاح الخاص Ed25519 الذي تحتفظ به لوحة التحكم؛ ويتحقق المثيل من التوقيع باستخدام المفتاح العام من `OPS_PUBLIC_KEY` (base64، 32 بايت خام). يغطي التوقيع طريقة HTTP والمسار مع سلسلة الاستعلام وتجزئة SHA-256 للجسم والطابع الزمني وnonce يُستخدم مرة واحدة:

```
canonical = METHOD \n PATH_WITH_QUERY \n sha256(body) \n timestamp \n nonce
```

الترويسات: `X-Ops-Timestamp` (ثواني Unix، ±5 دقائق)، و`X-Ops-Nonce` (يُستخدم مرة واحدة، للحماية من إعادة التشغيل)، و`X-Ops-Signature` (توقيع Ed25519 بترميز base64).

## نقاط النهاية

| الطريقة | المسار | الغرض |
|--------|------|---------|
| GET | `/api/v1/ops/info` | الإصدار، وعدد المستخدمين والبطاقات، وحالة قاعدة البيانات |
| POST | `/api/v1/ops/rescue-access` | إنشاء حساب مسؤول للمشغّل **محدد المدة** |
| DELETE | `/api/v1/ops/rescue-access` | إلغاء حساب الإنقاذ فورًا |
| GET | `/api/v1/ops/export` | بث حزمة تصدير مساحة العمل بعد إزالة الأسرار |

## وصول الإنقاذ — ضمانات الشفافية

صُمّم وصول المشغّل المحدد المدة («وصول الإنقاذ») بحيث لا يمكن أن يحدث دون علم المسؤولين:

- **يُخطر كل منح أو إلغاء جميع مسؤولي المثيل** داخل التطبيق *وكذلك* عبر البريد الإلكتروني، مع اسم المشغّل والسبب المذكور ووقت انتهاء الصلاحية.
- **يُسجّل كل إجراء في سجل أحداث المثيل نفسه.**
- **يفرض المثيل انتهاء الصلاحية بنفسه**: تحمل حسابات الإنقاذ طابعًا زمنيًا `access_expires_at`؛ ويُرفض الحساب المنتهي عند المصادقة وتُعطّله مهمة خلفية كل ساعة. ولا يمكن لانقطاع لوحة التحكم تمديد الوصول أبدًا.
- تستخدم حسابات الإنقاذ عنوانًا محجوزًا مخصصًا (`rescue-…@rescue.turboea.invalid`)، ما يجعل التعرّف عليها سهلًا في قائمة المستخدمين وإلغاء تفعيلها يدويًا في أي وقت.

## تصدير مساحة العمل

يعيد `GET /api/v1/ops/export` الحزمة نفسها التي يعيدها **الإدارة → الإعدادات → الترحيل → نقل مساحة العمل → تصدير**: مساحة العمل كاملة بعد إزالة جميع الأسرار. وتستخدمها لوحة التحكم لتصدير البيانات التي يطلبها العملاء (قابلية نقل البيانات بموجب GDPR) وللنسخ الاحتياطية الآمنة قبل الترقيات أو الحذف.
