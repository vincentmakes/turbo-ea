# 运维 API（托管部署）

运维 API (`/api/v1/ops`) 是 Turbo EA Cloud 控制平面用于运维托管实例的**可选**管理接口。在自托管安装中，它**默认禁用**——除非实例启动时设置了 `OPS_PUBLIC_KEY` 环境变量，否则所有路由均返回 `404`。Turbo EA 本身不包含任何计费或许可逻辑。

## 身份验证

每个运维请求都必须使用控制平面持有的 Ed25519 **私钥**签名；实例使用 `OPS_PUBLIC_KEY` 中的**公钥**验证签名（base64，原始 32 字节）。签名涵盖 HTTP 方法、包含查询字符串的路径、请求正文的 SHA-256 哈希、时间戳和一次性 nonce：

```
canonical = METHOD \n PATH_WITH_QUERY \n sha256(body) \n timestamp \n nonce
```

请求头：`X-Ops-Timestamp`（Unix 秒，±5 分钟）、`X-Ops-Nonce`（仅使用一次，防重放）、`X-Ops-Signature`（base64 Ed25519 签名）。

## 端点

| 方法 | 路径 | 用途 |
|--------|------|---------|
| GET | `/api/v1/ops/info` | 版本、用户/卡片数量、数据库健康状况 |
| POST | `/api/v1/ops/rescue-access` | 创建**限时**运维管理员账户 |
| DELETE | `/api/v1/ops/rescue-access` | 立即撤销救援账户 |
| GET | `/api/v1/ops/export` | 流式传输已剔除机密的工作区导出包 |

## 救援访问 — 透明性保障

限时运维访问（「救援访问」）经过设计，绝不会在不知情的情况下发生：

- **每次授予和撤销都会通过应用内通知和电子邮件通知所有实例管理员**，包括运维人员姓名、所述原因和到期时间。
- **每项操作都会记录在实例自己的事件日志中。**
- **由实例本身强制执行到期时间**：救援账户带有 `access_expires_at` 时间戳；过期账户会在身份验证时被拒绝，并由每小时运行的后台任务停用。控制平面中断绝不会延长访问权限。
- 救援账户使用专用保留地址 (`rescue-…@rescue.turboea.invalid`)，因此在用户列表中很容易识别，也可随时手动停用。

## 工作区导出

`GET /api/v1/ops/export` 返回与**管理 → 设置 → 迁移 → 工作区传输 → 导出**相同的包：完整工作区且已剔除所有机密。控制平面将其用于客户请求的数据导出（GDPR 数据可携权）以及升级或删除前的安全备份。
