# 自定义语言

Turbo EA 内置十种语言。当您的组织需要另一种语言时——荷兰语、波兰语、希伯来语、印地语、泰语，或巴西葡萄牙语这样的地区变体——管理员可以将其添加为**自定义语言**，并填写其翻译，而无需等待新版本发布。

自定义语言保存在您的数据库中，而不是应用程序代码里。您添加它、翻译它、审核它，并在准备好后将其提供给用户。内置语言不受影响。

自定义语言涵盖整个用户界面**以及**元模型给各项内容起的名称：卡片类型、子类型、分区、字段及其选项、关系、利益相关者角色、类别、仪表板、法规、资源类型和生命周期阶段帮助。

本页上的所有操作都需要 **admin.settings** 权限。

## 添加自定义语言

前往**管理 > 设置 > 常规**。**自定义语言**部分位于[启用的语言](settings.md)的正下方。

点击**添加语言**并填写：

| 字段 | 说明 |
|------|------|
| **语言代码** | 简短的语言代码：两到三个小写字母，后面可选地加上文字（`zh-Hant`）和两个大写字母的地区（`pt-BR`）——`nl`、`he`、`hi`、`th`、`pt-BR`。不能是内置语言的代码。 |
| **本地名称** | 用户在语言菜单中看到的名称，用该语言本身书写——*Nederlands*、*עברית*、*हिन्दी*、*ไทย*。 |
| **英文名称** | 该语言的英文名称——*Dutch*、*Hebrew*。AI 提供商就是根据它得知要翻译成哪种语言。只能使用字母、空格、括号和连字符。 |
| **从右到左的文字** | 对从右到左书写的语言开启，例如希伯来语、波斯语或乌尔都语。默认关闭；当代码属于通常从右到左书写的语言时，对话框会提示，但绝不会替您开启。 |

任何文字都可以：拉丁文、西里尔文、希伯来文、阿拉伯文、天城文、泰文等，包括这些文字所需的连接字符和标记。开启**从右到左的文字**后，选择该语言的用户看到的整个应用程序将从右到左排版，与阿拉伯语相同。

地区语言是一种独立的语言：`pt-BR` 不会借用内置的葡萄牙语，`zh-Hant` 也不会借用内置的中文。在字符串翻译之前，会以英文显示。

新语言默认处于关闭状态：在您提供之前，用户看不到它。列表中的每种语言都会显示一个进度条，说明已翻译的字符串数量，以及两个计数：

- **缺失**——尚无翻译的字符串。
- **在英文中已更改**——已翻译，但英文原文此后发生了变化的字符串。在重新翻译之前，用户看到的是旧翻译，这通常比回退到英文更好。

用语言的开关将其提供给用户。用户随后可以像选择任何内置语言一样，在语言菜单中选择它。仍然缺失的字符串会以英文显示。

## 从社区库安装语言

其他 Turbo EA 用户会在[社区语言库](https://github.com/vincentmakes/turbo-ea-translations)中分享他们的翻译。在您自己的语言下方，**社区语言**区块列出了库中的语言，每种语言显示其本族语名称和代码、已翻译的界面比例，以及制作其语言包时所用的 Turbo EA 版本。

!!! warning "由社区提供，未经审核"
    语言包由社区成员撰写。**Turbo EA 项目不会审核它们。** 自动检查可确保语言包不会加入英文文本中没有的标记、链接或损坏的占位符，但没有人检查翻译是否准确或完整。在向用户提供某种语言之前，请先自行审核。

**安装**会下载该语言的语言包并导入。具体过程如下：

- 语言包从社区库下载——正是库中列出的那个文件，并按其校验和进行核对。
- 每个字符串都要通过与[导入文件](#the-language-pack-file)相同的检查；被拒绝的字符串会列在报告中，且不会被保存。
- 新语言以**关闭**状态添加。请先在**审核字符串**中查看，然后再为您的用户开启。
- 报告会显示已应用的内容、被拒绝的内容及原因，以及您的 Turbo EA 版本中不存在的内容。

随后该语言显示为**已安装**，它在您自己语言列表中的行带有**由社区提供，未经审核**标记。安装失败——语言包无法下载、与库的校验和不符或不是有效的语言包——不会安装任何内容，并会记录在[安全与管理日志](audit-log.md)中。在**审核字符串**中，每条翻译都会显示其来源——*社区库*、*手动修正*、*AI 翻译*、*导入的文件*或 *MCP*。

当库中有您从中安装的语言的较新语言包时，该语言会显示**有可用更新**。**更新**会将新语言包合并到您的语言中。除非您勾选**同时替换手动修正的字符串**，否则您手动修正的字符串会被保留。您语言的名称、方向和开关保持不变。

如果您自己添加了某种语言，而库中有相同的代码，则其行会显示**在此服务器上添加**，并提供**添加社区字符串**：语言包会以同样的方式合并到您的语言中——除非您另行选择，否则手动修正的字符串会被保留——随后该语言会被标记为由社区提供。

Turbo EA 仅在您提出请求时才会联系该库：首次显示该部分时会下载并保存列表；之后会显示已保存的列表（附下载日期），直到您点击**刷新**。后台不会进行任何检查，因此较新的语言包只有在刷新后才会显示为**有可用更新**。如果无法连接到库，该区块会给出提示，并继续显示上次成功下载的列表。

### 关闭社区库

库的地址由环境变量 `LANGUAGE_CATALOGUE_URL`（Helm 值 `customLanguages.catalogueUrl`）设置。将其设为空值即可关闭该功能，例如在无法访问互联网的安装中；此时该区块会提示社区库已关闭。您也可以将其指向您自己服务器上的库副本：语言包从与其 `index.json` 相邻的 `packs/<code>/pack.json` 文件下载。

### 贡献语言

翻译了库中尚没有的语言，或改进了某种语言？请使用**导出语言包 > 分享（社区包）**导出，并向库提交——请参阅其[贡献指南](https://github.com/vincentmakes/turbo-ea-translations/blob/main/CONTRIBUTING.md)。

## 三种翻译方式

选择适合您的方式；它们可以组合使用，结果相同。

### 1. 导出文件并导入回来

**导出语言包**会下载一个语言包文件（JSON）。选择其中包含的内容：

- **新增和已更改的字符串（待翻译）**——每个缺失或已更改字符串的英文文本。用于首次翻译以及每次升级之后。
- **全部英文字符串（待翻译）**——每个字符串的英文文本，用于全部重新翻译。
- **当前翻译（包含此安装自有的标签）**——您已有的翻译，包括您自己元模型中的名称。用作备份，或将该语言迁移到您自己的另一个安装。
- **分享（社区包）**——您已有的翻译，但仅包含每个 Turbo EA 安装中都相同的内容：界面文本，以及 Turbo EA 所提供的内置元模型的名称。凡是您的安装特有的内容都会被排除——您创建的卡片类型、字段和选项、您重命名的内置名称、您的仪表板和类别。这就是适合与其他 Turbo EA 用户分享的文件。

可以在任何地方翻译该文件——翻译机构、翻译工具或 AI 聊天——然后选择**导入语言包**。导入会检查文件，逐个分区保存字符串，并显示报告：应用、未更改或已清除的字符串数量，哪些被拒绝及原因，以及哪些键不在此版本中。

### 2. 使用您的 AI 提供商翻译

如果已在 [AI 功能](ai.md)中配置了 AI 提供商，**使用 AI 翻译**会在后台翻译该语言。请选择：

- **新增和已更改的字符串**——仅限缺失和已更改的字符串。这是通常的选择。
- **全部**——重新翻译每个字符串。您手动修正的字符串会保留，除非您同时勾选**同时替换手动修正的字符串**。

对话框会显示将发送多少个字符串，然后在运行时显示进度；您可以关闭它稍后再回来，也可以**停止翻译**。您的卡片类型、字段和关系的名称会最先翻译，随后以这些名称为参考翻译界面其余部分，使同一事物在各处名称一致。AI 返回的无法使用的字符串不会被保存；它仍然缺失，并在下次运行时重试。

此选项不依赖于是否开启了卡片的 AI 描述建议——只要求已配置提供商。

### 3. 通过 AI 助手（MCP）

通过 [MCP 集成](mcp.md)连接的 AI 助手可以使用三个工具为您翻译该语言：

- `list_custom_languages`——存在哪些自定义语言，以及每种语言翻译到了什么程度。
- `get_untranslated_strings`——仍待翻译的英文字符串，逐页提供，并附带翻译说明。
- `submit_translations`——将翻译发送回来。它会先预览，确认后再保存，与所有 MCP 写入工具一样。

例如，可以这样请助手：*「翻译我们荷兰语自定义语言中缺失的字符串，先从元模型名称开始。」* 助手使用您自己的权限工作，它所做的每项更改都会记录在审计日志中。

## 语言包文件

语言包是一个如下所示的 JSON 文件：

```json
{
  "format": "turbo-ea-language-pack",
  "format_version": 1,
  "app_version": "2.214.0",
  "locale": {"code": "nl", "name": "Nederlands", "english_name": "Dutch", "rtl": false},
  "mode": "missing",
  "instructions": "Translate every value under \"strings\" from English into Dutch. …",
  "strings": {
    "metamodel": {
      "type.Application.label": "Application",
      "type.Application.field.businessCriticality": "Business Criticality"
    },
    "common": {
      "actions.save": "Save",
      "actions.cancel": "Cancel"
    }
  },
  "source_hashes": {
    "metamodel": {
      "type.Application.label": "5c1e0a9d7b32",
      "type.Application.field.businessCriticality": "a90d3f17c4e8"
    },
    "common": {
      "actions.save": "1f3a9c0b2d4e",
      "actions.cancel": "7b2e4d6a8c01"
    }
  }
}
```

- **strings** 保存待翻译的文本，按分区分组（`metamodel`、`common`、`admin`、`cards` 等）。只翻译**值**；绝不要更改键。
- **metamodel** 分区保存卡片类型、字段、选项、关系的名称，以及存储在数据库中的其他标签。它们是界面其余部分所引用的简短标签：请最先翻译它们，并在其他各处使用相同的词语。
- 双花括号中的所有内容，例如 `{{count}}` 或 `{{name}}`，必须原样保留：应用程序会在那里填入一个值。同样保留 `<1>` 和 `</1>` 之类的标签，以及 `$t(common:actions.save)` 之类的引用。
- **source_hashes** 记录每个字符串是依据哪段英文文本生成的。请将其保留在文件中：导入时，Turbo EA 据此判断自文件导出以来英文是否发生了变化。对于 **metamodel** 分区，它是必需的——缺少哈希的条目会被拒绝——因为正是它防止翻译落到期间被重命名的名称上。
- **instructions** 用通俗的语言重复这些规则，因此您可以将文件原样交给翻译人员或 AI 聊天。

导入时，每个字符串都会单独检查。此版本的 Turbo EA 没有的键——来自为其他版本制作的包——会被计为不在此版本中，并在报告中列出。当字符串为空或比英文长得多、丢失或增加了占位符或 `$t(...)` 引用，或引入了英文原文没有的标签或链接时，它会被拒绝。在 **metamodel** 分区中，不带哈希的翻译同样会被拒绝；如果其所依据的名称自文件导出以来已被更改，则会被跳过——「Application」的翻译绝不会落到被别人重命名的卡片类型上。与已存储翻译相同的翻译会报告为未更改。被拒绝的字符串绝不会阻止其他字符串被保存。

为其他语言代码导出的文件仍可导入；导入前会要求您确认。

## 审核和修正字符串

**审核字符串**会列出某种语言的字符串，并在每个翻译旁显示英文原文。可按分区、按状态（缺失、在英文中已更改、已翻译）或按文本筛选，并就地编辑或清除任何翻译。您的修正在保存后立即生效。

## 升级之后

每个 Turbo EA 版本都会新增和更改一些英文文本，您也可能重命名元模型中的内容。之后，自定义语言会将新字符串显示为**缺失**，将已更改的显示为**在英文中已更改**——其余所有内容保留其翻译。可用上述三种方式中的任何一种补齐差距：导出新增和已更改的字符串，以**新增和已更改的字符串**运行**使用 AI 翻译**，或请您的助手处理。

您手动做出的修正会保留。对**全部**运行的 AI 翻译不会改动它们，除非您勾选**同时替换手动修正的字符串**。

## 限制

- **文档站点不在范围内。**本手册仍保留内置语言版本。
- **调查沿用其创建时的标签。**在某个字段的选项被翻译之前创建的调查，会沿用其创建时的选项标签。
- **复数形式。**英文有两种复数形式（*one card*、*2 cards*）。形式更多的语言——例如波兰语、俄语或阿拉伯语——可以在导入的文件中，在英文形式旁边添加额外的形式（`_few`、`_many` 等）。包中没有的形式会回退到该语言自己的通用形式（`_other` 翻译），绝不会回退到英文。AI 翻译和审核界面也会处理已存储的额外形式，但不会创建新的形式：请通过文件添加。
- 删除自定义语言会移除它的所有翻译，包括卡片类型、字段的名称和其他元模型标签。选择了该语言的用户会切换回英语。
