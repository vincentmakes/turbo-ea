# Source and licenses

Turbo EA adapts the static review procedure from GetSentry’s `security-review`
at commit `a582c51ee29d0f35e6ac321340796f77d43da733`.
[Upstream source](https://github.com/getsentry/skills/tree/a582c51ee29d0f35e6ac321340796f77d43da733/skills/security-review)

This edition changes the invocation name, uses explicit activation and limits
the workflow to static inspection and a chat response. It adds Turbo EA’s
authorization and card visibility checks. The upstream repository license is
Apache License 2.0. [Repository license](LICENSE.apache-2.0)
