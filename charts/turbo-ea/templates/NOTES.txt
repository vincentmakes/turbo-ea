Turbo EA {{ .Chart.AppVersion }} is being deployed as release "{{ .Release.Name }}" in namespace "{{ .Release.Namespace }}".

{{- if .Values.ingress.enabled }}

Open {{ .Values.publicUrl }} once the Ingress has an address:

  kubectl get ingress -n {{ .Release.Namespace }} {{ include "turbo-ea.fullname" . }}
{{- else }}

No Ingress was created. To reach the app from your machine:

  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "turbo-ea.fullname" . }}-nginx 8920:{{ .Values.nginx.service.port }}

then open http://localhost:8920 (the browser URL must match publicUrl for
cookies and CORS; set publicUrl=http://localhost:8920 for a port-forward
evaluation).
{{- end }}

The FIRST user to register becomes the administrator — register right away.

Check the rollout:

  kubectl rollout status -n {{ .Release.Namespace }} deployment/{{ include "turbo-ea.fullname" . }}-backend
  helm test -n {{ .Release.Namespace }} {{ .Release.Name }}
